# 🎮 Консольная игра «Камень, Ножницы, Бумага» на Python

Интерактивная консольная игра с поддержкой двух игровых режимов, защитой от некорректного ввода данных и скрытым вводом для честной игры вдвоём.

## ✨ Особенности проекта
* **Два режима игры:** Матч против искусственного интеллекта (бота) или локальная игра для двух игроков.
* **Полная валидация ввода:** Программа защищена от падений при случайном вводе букв, пустых строк или некорректных чисел с помощью методов `.isdigit()`.
* **Режим скрытого выбора:** Для игры вдвоём используется встроенный модуль `getpass`, который скрывает вводимые символы на экране, чтобы соперник не мог подглядеть чужой ход.
* **Гибкая настройка:** Возможность задать количество победных раундов перед стартом игры.
* **Вариативность:** Случайный выбор финальных фраз для победителей и проигравших.

## 🛠️ Использованные технологии
* **Python 3** — основной язык разработки.
* **random** — для генерации ходов бота и выбора победных фраз.
* **getpass** — для реализации безопасного скрытого ввода.
